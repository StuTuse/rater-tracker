## Electron 与安装

`npm run desktop:smoke` 以及 `node scripts/desktop-smoke.mjs 'release/win-unpacked/Rater & Tracker.exe'` 成功。实际 `app://rater` 窗口验证：隔离 Node 环境、11,000,000 micro-XP 持久化、备份校验、旧 revision 拒绝、48/48 离线徽章资源加载；有实际桌面截图。

`npm run dist` 成功生成完整运行时与 NSIS 安装包。`scripts/install-acceptance.ps1`：

1. 安装到已核验的工作区 `runtime-data/install-check`；正常个人数据目录不参与测试。
2. 桌面快捷方式存在，TargetPath 指向实际安装 EXE。
3. 实际安装 EXE 启动检查成功；再次启动的新进程正常退出，原实例保持。
4. 同版本再次安装后，用户数据路径、11 XP、revision=1 一致。
5. 结束运行并卸载测试安装；保留源码构建产物和隔离测试报告。

实际结果在 `output/install/report.json`、`output/desktop/report.json` 与截图。运行资源从 app 协议本地加载，不依赖预览服务器。最终安装复验一度因检查过早读取新图片 complete 返回失败；改为等待图片 decode 并读取全部徽章文件，重新构建和安装复验通过。没有跳过这个失败或将它当作成功。
