# 1.0.1 反馈修复验收 · 2026-10-20

本轮由main工作区统一负责共享UI／会话模块、Windows账号IPC、Android触控样式、版本与测试／文档／发布。用户允许使用Android Studio模拟器代替实体手机；仅使用RaterSigningAcceptance专用AVD与虚构测试账号，没有触及实际用户账号或数据。

## 实际修复

- 手机任务筛选容器取消拉伸，按内容宽度排布，窄屏允许换行；滑块不得接收输入。
- 手指按住期间暂缓保存／同步引起的DOM重整，状态仍正常落盘；松手后的点击完成再刷新。触控反馈使用颜色与阴影、不移动按钮，DOM更新保留按压状态。
- Android普通界面禁止长按选字，输入框／textarea保留原生编辑与文字选择。
- 趋势范围和序列切换仅对图表／日期标签交叠渐变；月份切换仅更新日历／月份标题；当天回顾及评分原文使用各自局部快照。完整240ms、柔和120ms、关闭不动画。快照inert且pointer-events:none，连续切换及时清理旧快照；静态标题／按钮不跟随闪烁。
- 图表缓存加入实际日期，修复不同空白日期范围数值相同而保留旧点击日期的问题。
- 等级框电脑68×76、手机60×68，等级文字16／15px；四项图标底座电脑36、手机34px。面板圆角统一16px，评分／任务卡14px。
- 今日最多3项任务，手机在“今日记录”下、评分之前；超过3项有“查看全部”直达完整任务页，无任务时评分在前。桌面账号入口在左下版本号上方，紧凑侧栏保留头像；手机继续顶部入口。
- 会话恢复时先尝试持久刷新令牌，访问令牌失效不直接退出；串行保存最新凭证，设备标识恢复顺序兼容旧格式。用户打开／点击／输入／滚动记录活动，后台轮询与SDK令牌更新不延长30天闲置；到期在运行中也拒绝同步。离线保留同主体身份与业务空间，凭证撤销／身份不符要求重登。
