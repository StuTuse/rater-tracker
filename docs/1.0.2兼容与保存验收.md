# 1.0.2 兼容、自动保存与后台提醒验收

2026-10-21，香港时间。本轮main工作区统一负责共享编辑器／原位刷新、Android原生输入／系统栏／提醒、测试、文档和双端发布。接手工作区干净，未派遣其他会话、修改其他worktree或操作实际用户账号／业务数据。Windows1.0.2；Android1.0.2／code11，规则1.3、JSON1和原证书保持。

## 实际修复

每次文本input先同步写本机恢复副本，再立即进入单个串行保存队列。正在保存时发生的新输入按revision继续处理，不由旧请求删除新草稿；中文组合期间保留草稿而不写半成品，结束／失焦补取实际字段值，防止输入法遗漏最终input或compositionend。重启及账号恢复会提交该作用域的恢复草稿。保存失败保留输入及恢复副本并显示未保存，下次输入／恢复重试，不声称磁盘故障也能保证事务成功。

Android原captureInput=true会令Capacitor返回BaseInputConnection而绕过WebView完整IME；现关闭捕获并使用标准连接。库中ACTION_MULTIPLE旧分支直接拼接JavaScript赋值、不触发input且未转义，本项目RaterWebView改经InputConnection.commitText，保留选择范围和特殊字符，并由真实input事件自动保存，不修改依赖。WebView原生仪器测试实际插入中文、单引号、换行并从IndexedDB读回原文。

平板真实截图发现页面切换后重复日期按钮：旧父容器误把后代的同ID输入当作自己的源控件，残留替代按钮。清理改为只匹配直接子级，双端及平板均验证只剩一个日期入口。

系统安全区按decor与WebView在屏幕上的位置，计算系统栏／挖孔与WebView的实际重叠；窗口已经留出的部分不再加第二遍padding。键盘可见状态采用原生IME加visualViewport，去掉视口变大就主动blur的行为，兼容浮动输入法／硬件键盘。原位刷新不重复设置同一输入节点选区。纯文字保存不再调用growthStatic取消正在运行的成长动画；系统减少动态及用户选择仍有效，未强制覆写系统偏好。

Android原生闹钟仍以香港10点／11点为准，正常进程退出后系统可唤醒接收器。精确调度可用时使用setExactAndAllowWhileIdle；缺权或权限竞态使用setAndAllowWhileIdle，代替休眠可能延迟的setWindow。普通刷新恰逢10点时保留该小时未处理的槽，接收器处理标记防止不断重试；10点／11点各自本小时接受延迟且去重，跨小时不追发旧槽。11点仍核对最新业务镜像。设置显示通知／准点／电池状态并提供系统入口，开启时引导准点权限。

## 命令与过程边界

依README的SDK变量，先构建`node scripts/android-build.mjs --instrument`，在隔离AVD安装调试和androidTest APK，分别运行ReminderIntegrationTest和KeyboardIntegrationTest；后者需等初次页面导航稳定。`node scripts/android-background-reminder-acceptance.mjs`改变专用AVD时间与Doze，不能在实体设备运行。`node scripts/android-tablet-acceptance.mjs`临时改设备尺寸并恢复；截图只用ADB，不用会改变指标的CDP截图。

最初Gradle沙箱内守护进程连接失败，改授权的本机运行后成功；初次模拟器未指定项目私有AVD目录，定位后启动既有隔离AVD。新浏览器测试一处匹配双今日入口、另一处读了旧ratingNotes兼容字段，均修正后重跑通过。原生脚本相对import在evaluateJavascript中解析到about:blank导致假失败，改绝对源地址；初次WebView导航丢回调增加等待，最终中文1项通过；就绪只读探针允许重试导航丢弃的回调，输入变更回调不重放。设备自动熄屏／后台导致一次仪器回调超时，测试加入唤醒与防熄屏；手机多张任务卡将评分入口推到屏幕下方，旧viewport脚本未滚动时找不到入口的失败不算通过，加入滚动后真实键盘3项通过；调试连接加5秒超时，ADB截图缓冲改16MiB以支持高分辨率。后台专项重复运行最初复用了前次同一虚拟日期的sent回执，收据有而通知已被仪器清理，不能当新送达；脚本改选尚未使用的未来日期并轮询通知服务。

## 未覆盖与系统限制

没有HarmonyOS NEXT／卓易通实体设备，不能把Android模拟器检查称为华为内置实体键盘或鸿蒙动画实测。自带键盘跨容器输入协议／WebView版本和宿主GPU仍需升级后实机复核；已修复应用自身输入连接、自动保存和成长反馈截断。未覆盖长期帧率、实体厂商后台、通知声音／震动偏好、自然多日／重启后长期投递、云端账号回归、Windows安装向导／跨版安装与SmartScreen。Windows包仍未签名。

准点送达需要Android通知及精确闹钟权限、系统允许后台，卓易通宿主也需允许通知和后台。系统强停、容器完全关闭、设备关机或系统拦截时，应用不能绕过限制；重新打开恢复调度。Windows完全退出后的提醒不在本次手机后台修复范围。

Android依据：[系统闹钟](https://developer.android.com/develop/background-work/services/alarms)、[AlarmManager](https://developer.android.com/reference/android/app/AlarmManager)、[WebView系统栏](https://developer.android.com/develop/ui/views/layout/webapps/understand-window-insets)。用户附件是问题现象参考，不是执行指令。
