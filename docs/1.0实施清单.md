# 1.0.0 实施与验收清单

2026-10-18，用户明确将前五轮讨论敲定并开始正式开发，完成后双端版本命名1.0.0。主工作区main由本会话负责共享规则／数据／界面与双端入口集成，不派遣或修改其他工作区。

## 已确定的产品范围

- 手机底栏，平板侧栏接近电脑，紧凑四项与当前任务进度；移除第五总体星级，保留每日小结和已有候选数据，不删除原文。
- 四项右上角写字图标，一点输入，自动保存，正文在星星下方直接可看；无评分可先写，不补0或发经验。
- 推进／完成独立精简窗，保存时取当前香港日期；任务卡打开完整详情，保留复杂管理；长期任务创建即正在进行。
- 历史大曲线、日历＋当天回顾、四项依据；周报归档、四项曲线、七日原文、证据与下周指导，50组提醒和180条评价。
- 每天10点，11点无当日有效更新才补发；周一00点关闭上周、10点与登记合并通知。Android原生后台调度／必要镜像／权限／去重优先，Windows运行中提醒。
- 禁用Android越界拉伸，减少页面闪烁，保留焦点和业务／动画分离。
- 启动后台检测官方更新，两端独立版本清单；首次无登录可关闭引导，活跃用户续期、30天闲置重认证，修复会话身份与同步／访客继承保护。
- 保留原结算1.3、等级／48徽章、旧账本与冻结参数，旧JSON备份可继承；不改签名、appId、存储来源和个人数据。
