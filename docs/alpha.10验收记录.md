# alpha.10 登录表单与连续弹窗动效

日期：2026-10-13，香港时间。产品文档 v1.12、视觉 v1.8，结算1.3／备份格式1。

## 实际改动

新增 src/modal.js 统一控制外框几何与关闭清理。账号界面原先切换时 innerHTML 重建，密码、邮箱和验证码丢失，并对整个 dialog 降低透明度；现登录、注册、验证面板保持各自 form/input 与分段滑块节点，按 hidden 切换，标题与说明原位更新。待验证流程可切回登录再返回验证码；重新填写保留原注册输入，成功登录后移除表单。

切换只以420ms插值外框实际宽高，不降低内容透明度或缩放文字；柔和150ms、关闭无变形。实际尺寸测量在 showModal 后执行，修复初次滑块零尺寸。暖白外框、金色边线与头像细节略作调整。

用户追加允许大写开头，界面、客户端与原生注册接受6～25位大小写字母、数字、_或-，首位为字母。新增src/username.js统一生成小写认证标识，用于注册与密码登录，以兼容已经确认的云端小写正则。界面说明登录不区分大小写；原始显示名由既有加密会话标签保存，同名不同大小写属于同一账号。未修改云端身份配置或批量改写账号。

关闭前冻结当前宽高并保持 data-kind、内容和背景滚动锁定。沿用共同280ms变换／200ms透明度及遮罩退出；结束后才清空密码／验证码、清布局样式并返回入口焦点。快速重开取消旧清理和旧变形，防止旧回调清除新窗口。非敏感草稿在当前运行的表单节点中保留；密码／验证码不写入数据库、备份、localStorage或凭证文件。

用户再次报告关闭闪烁拉伸，复现于打开动画未结束即关闭：getBoundingClientRect把420px外框读成约413.7px，写回宽高导致文字重排。现变形与冻结均从getComputedStyle读取未缩放的布局尺寸，所有dialog保持固定定位与fit-content，避免退出:modal时原生定位改变。新增逐帧检查快速关闭时外框／输入框尺寸不变、透明度不回升。
