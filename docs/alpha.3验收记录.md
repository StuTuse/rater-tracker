# alpha.3 可读性与经验条动效验收

日期：2026-10-12，香港时间。版本 **0.1.0-alpha.3**。产品文档 v1.5、视觉规范 v1.3；结算规则仍为 1.3，备份格式仍为 1。

## 实际改动

正文基准 15px，操作与说明通常 12～14px；加深说明、表单、表格、徽章信息和经验数字，进一步降低背景底纹对比。类别说明可换行，窄窗口采用单列内容，星按钮弹性分配宽度。调整按钮按压、徽章悬停与弹窗进入节奏。

经验条采用三层金色光团、缓慢掠过的高光和柔润端点；光层裁切在实际填充内。完整模式低亮度循环，柔和／系统减少动态停止循环，关闭模式完全静态；隐藏时暂停装饰并落到已保存状态。常规过渡约 820ms，跨级约 1,280ms，柔和约 300ms。

`src/app.js` 分别管理循环装饰与有限的反馈动画；取消反馈前读取实际显示的宽度和累计数字，使中途更正从当前显示位置继续。静态恢复、冲突重读、减少动态切换会取消旧数值动画与庆祝计时器。经验条的屏幕阅读器描述补充等级、本级值与门槛。业务与冻结参数没有改变。

文字检查抽样六类：类别说明、评分明细、表单提示、页面副标题、经验变化提示和本级进度；字号至少 12px，在对应奶油色基底上对比度至少 4.5:1。没有覆盖全部文字、纹理像素和辅助功能，不能作为全软件 WCAG 审核。

中途衔接在真实 renderer 里观察动画取消前的实际宽度与下一段起点，误差小于 2px；再次点击通过 DOM 事件在反馈仍播放时触发，避免自动化点击等待卡片进入动画结束而错过时机。业务操作仍走真实保存事务。

隐藏检查通过模拟 `document.hidden` 与 visibilitychange 验证处理器，不代表已经在所有 Windows 最小化／锁屏情境人工验证。125% 检查使用实际 Chromium 的 CSS zoom，辅以 800／390px 视口；不等于全部系统 DPI 设置验收。

## 发现与修正

- 放大截图中星按钮越出卡片，修正为弹性宽度与受限图标，并新增局部边界检查；最终截图在 `output/playwright/alpha3-zoom125.png`。
- 首次专项脚本漏点“清空评分”确认，造成等待超时；补齐实际流程后通过。
- 自动化点击等待卡片稳定，使第一次中途测试没有真正中断动画；改为在反馈期间派发第二次点击并检查真实衔接。
- 减少动态时仍有一次短暂的透明度过渡；检查改为区分有限过渡与循环光层，循环已停止。没有用取消短过渡的方法掩盖动画问题。

实际查看今日、历史、奖励中心、窄窗口、125% 与安装版截图。动效录制：`output/playwright/alpha3-xp-flow.mp4`，1440×960、30fps，包含增长、升级和回退；这是预览录制，不是 60fps 性能测量。脚本在结束时恢复隔离浏览器原快照。截图、视频和报告均不入库。
