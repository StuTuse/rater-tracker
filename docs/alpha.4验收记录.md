# alpha.4 文案与交互体验验收

日期：2026-10-12，香港时间。应用 **0.1.0-alpha.4**，产品规范 v1.6、视觉规范 v1.4；结算规则仍为 1.3，备份格式仍为 1。

## 实际改动

移除页面英文装饰标题、类别口号、侧栏鼓励段落和重复保存提示，使用“今日评分、任务、历史记录”等功能名称。日期、状态、入账数值、评分参照、备份覆盖风险和必要规则继续显示。

新增 `src/dom.js`，按稳定键和节点类型更新变化的属性、文字和子节点；评分卡片、星按钮、备注及任务表单保持原节点。评分、阶段与设置保存保留草稿、光标、展开状态和滚动位置。任务详情同样使用原位更新。

悬停／键盘焦点预览星数，不写入记录；移开恢复已保存状态。按压即时回应，保存成功后只为变化的星星播放动画：完整模式点亮约 360ms、熄灭约 240ms、星间错开 24ms；柔和模式 150ms 透明度过渡，关闭模式静态。连续改分取消同一元素旧动画。卡片、按钮、筛选、日期和输入框补充悬停、按压、阴影与焦点反馈。

普通评分使用星数、入账明细与经验条变化反馈，错误及徽章变化保留提示。无经验变化的备注保存不打断经验动画。恢复／重读直接更新星数，并暂时关闭星图标颜色过渡，避免重播历史反馈；导入不取消持续光层。数值核心、历史冻结、数据来源及生图原图未变。

## 发现与修正

- 整页闪烁来自每次保存的 innerHTML 替换；改为稳定节点更新，并验证四张评分卡和按钮的对象身份保持。
- 首次 UI 夹具遇到非当天评分日期；验收明确设置当天，避免把禁用备注当作可编辑输入。
- 入场检查最初把尚未结束的既有动画也判作重播，改为比较动画对象身份，检查是否出现新入场动画。
- 连续点击检查最初只等到中间的“2 星”。本地工具实现对异步 waitForFunction 谓词未进行真假轮询，随后读取到了 4 星中间状态；改用 evaluate 内有限轮询，等六次持久化 revision 全部完成，再核对 DOM 与实际评分。点击和 put 顺序同步记录。诊断钩子一度读取设置页不存在的日期，已修正并复验。
- 基于等待帧数的中途检查没有稳定建立中断时刻；改为将真实 WAAPI 固定在 25% 后提交下一次评分，检查实际显示宽度和取消后的新起点，误差小于 2px。这是受控渲染检查。
- 静态重读仍触发星图标 CSS 颜色过渡；更新期间关闭该过渡，最终恢复检查通过。

## 检查边界

浏览器的节点与动画检查不能代表全部原生交互已经人工验收。桌面验证包含实际窗口、资源、保存和安装升级，没有完整逐项重做鼠标／键盘手工流程。文字对比为六类抽样，125% 使用 CSS zoom，隐藏通过事件模拟；受控动画接续不是帧率测试。

仍需长历史量性能、60fps／GPU 实测、原生备份对话框完整点击、完整辅助功能审计、人工连续使用和原图体积优化。本轮未新增依赖、改动结算或迁移数据格式。
