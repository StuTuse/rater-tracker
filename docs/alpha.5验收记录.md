# alpha.5 应用内控件与二级界面动效验收

日期：2026-10-12，香港时间。应用 **0.1.0-alpha.5**，产品文档 v1.7、视觉规范 v1.5；结算规则 1.3、备份格式 1。

## 实际改动

新增 `src/controls.js`。所有 select 和 date 原字段继续负责 FormData、日期范围与校验，界面由应用内按钮、选项浮层和月历呈现。下拉菜单提供金色选中背景、勾选、悬停及焦点；月历提供月份导航、当日与选中日、禁用范围和香港日期“今天”。菜单在所属模态弹窗内挂载并进入顶层，滚动／窗口变化时跟随定位。

横向分段菜单的选中底板保持同一节点，滑动约 320ms、宽度约 280ms。弹窗使用 display／overlay 离散过渡，关闭后的 280ms 内完成淡出、收回与遮罩退出；弹窗内部内容切换约 220ms。折叠详情使用 details-content 的高度与透明度双向过渡。页面、弹窗、表格与横向菜单隐藏系统滚动条，保留滚动能力；模态打开锁定背景滚动。

菜单与日历支持鼠标、Enter／Space、方向键、Home／End、Tab 和 Esc；Esc 先关闭浮层，保留父弹窗。关闭中的浮层立即 aria-hidden 与 inert，结束后移除。原位更新保留生成控件和滑动底板，清理不再对应原字段的按钮；首次推进冻结后，详情字段变化不会残留重复控件。完整／柔和／关闭与系统减少动态也覆盖 details-content、backdrop 等伪元素。

## 发现与修正

- 将浮层放在 body 时，模态弹窗会拦截真实鼠标点击；改挂到所属 dialog 内，鼠标选择复验通过。
- 以字段序号作为身份会在详情结构变化后变化；改用表单与字段名，清理孤立按钮，验证推进冻结后的字段与按钮一一对应。
- 滚动事件直接关闭浮层会把浏览器自动滚动到控件的行为也当成退出；改为滚动中跟随定位。
- 退出浮层在偏好切到关闭时可能短暂留下可访问的旧选项；立即标记 inert／aria-hidden，并在下一次打开时清理旧退出节点。
- getAnimations 未列出 details-content 的高度过渡；检查改为真实打开／关闭中间高度，验证两方向均介于起止高度之间。
- 首次桌面 smoke 后台窗口被 Chromium 节流，截图保留旧帧，退出／滑块采样失败。仅对 smoke 窗口禁用后台节流，恢复真实渲染后全部条件通过；正常应用行为保持既有设置。这不是性能测量。
- 初始 Node 测试被沙箱阻止子进程，受审查执行后通过；一度因自动审批服务额度限制中断浏览器验收，恢复后继续完成。

## 检查边界

这是控件状态与真实渲染验收，不是完整辅助功能审计或实时帧率测量。桌面 smoke 使用 DOM 点击，新菜单真实鼠标／键盘路径在浏览器验证；尚未逐项人工点击所有桌面二级界面。Windows 原生备份文件对话框不属于应用内 select／date 控件，本轮未替换或全程点击。

生图素材保持，本轮未重跑像素 alpha 测量。仍需长历史量性能、60fps／GPU、完整辅助功能、连续人工使用与原图体积优化。同格式升级不能推广为未来格式迁移已经验证。
