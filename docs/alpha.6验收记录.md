# alpha.6 账号登录与同步验收

日期：2026-10-13，香港时间。规则 1.3、备份格式 1；产品文档 v1.8。

## 已实现

- 设置页用户名密码登录与退出，CloudBase 官方认证；个人账号在控制台创建／重置密码。
- Windows 受限 IPC 调用官方 Node SDK，会话通过 safeStorage 加密落盘；没有管理员部署凭证进入应用。
- 原未登录 IndexedDB current 保留；各账号独立键与同步元数据。登录不自动上传旧记录，可先备份再复制。
- 完整快照同步，保存＋dirty 原子提交，inFlight 持久化，上传中继续输入不会被旧确认清除。前台一分钟、保存、启动、网络恢复触发同步。
- PostgreSQL RPC 按 auth.uid() 隔离，角色显式检查；私有表无客户端直接访问，行锁 CAS 与请求回执同事务。
- 冲突暂停自动覆盖，先导出本机备份再下载；云端下载完整校验，历史奖励／冻结参数保留且不重演。

## 失败与处理

- 初次检查环境才发现无文档数据库，已改为 PostgreSQL RPC，移除未部署的 NoSQL 实现。
- 免费体验套餐拒绝添加网页安全域名；桌面改用官方原生 Node SDK，不关闭 Electron 隔离或放宽网页域名。浏览器登录未验收。
- PostgreSQL 显式 postgres 角色在共享实例不存在，使用平台默认管理角色成功部署。
- 会话恢复的 SDK 用户对象含非可序列化属性；只返回字符串 ID／显示名称后重启通过。
- 截图过早捕捉旧帧，增加绘制等待后查看实际登录／已同步界面。
- 一次打包下载 Electron 超时；后续构建完成下载并生成 alpha.6 安装包。
