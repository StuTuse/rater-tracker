# alpha.9 居中弹窗与注册规则修正

日期：2026-10-13，香港时间；产品v1.11、视觉v1.7、结算1.3／格式1。

用户反馈账号浮层位置、速率有误，要求弹到窗口正中并与现有动画一致。移除各断点的侧边／底部锚点和角落变换原点，采用inset:0、margin:auto、fit-content高度、中心原点；长表单限制最大高度后内部滚动。没有覆盖共享dialog动画：变换280ms、透明度200ms、内容切换220ms，与任务弹窗相同，柔和／关闭共享偏好。

用户提供真实错误：invalid SignUpRequest.Username，后端正则为^$|^[a-z][0-9a-z_-]{5,24}$。此前界面／原生允许大写、部分标点、5位，导致发码后验证注册被拒。现非空用户名采用6～25位小写开头、后续小写／数字／_-；界面pattern、客户端发送及原生注册先行检查，登录上限同步25。不会静默小写化账号。旧错误流程需修正账号并重新发码；对残留同类服务错误提供可读提示。
