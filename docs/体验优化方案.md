# 界面、记录与账号体验优化 · 讨论稿

日期：2026-10-18，香港时间。状态：首轮交互预览，等待讨论界面取舍；应用功能尚未实施。

本轮负责：本文、`docs/previews/experience-refresh.html`、README／CHANGELOG／WORKLOG／SESSION_HANDOFF 的对应记录。主工作区 main；不改另一工作区、不操作个人记录或云账号。现有 Windows alpha.21／Android alpha.6 保持。

## 1. 已确定的需求

- 平板改为左侧导航；手机也需重新比较导航位置、组件密度与操作效率。
- 保留黄色主色、少量绿色辅助、手绘素材风格，统一精简空白、重复说明与过大的组件。
- 关闭 Android 滚动边界的整体拉伸效果，改善连续操作和动画闪烁。
- 四项评分上方居中增加「今日评分」，使用相同的卡片语言，下方可写今日小结。
- **用户已明确选择：总体评分与小结独立记录，不增加经验。** 原四项 `5 + 2 × 星数`、补记折扣、等级曲线、任务冻结规则及48枚徽章条件保持；总体星数不加入现有四项星数徽章／全项完成统计。
- 历史趋势增加总体评分，旧日期留空，不能用0或四项均值填补。
- 软件启动后后台检查新版本，有更新时提示并提供下载选项。
- 保留已保存数据；修复账号同步和会话续期。目标为活跃使用持续登录，连续约30天未使用再引导重新认证。
- 首次安装、无登录会话时主动展示可关闭的登录界面，关闭后完整离线使用。

### 建议采用的排布原则

- 按应用窗口有效宽度切换布局，不按「Android」统一套手机底部栏。初始建议：≥1100px桌面完整栏；700～1099px平板窄侧栏；更窄手机采用讨论选定方案。分屏和横屏按实际宽度重算。
- 平板顶部成长卡控制在约80～96px；缩短页头和日期控件的重复纵向留白，日期与标题在空间允许时同排。
- 总体卡与四项卡使用同一边框、圆角、星级控件；总体卡限宽并居中，四项保持2×2。手机优先单列，避免将五颗星触控区压进半屏。
- 紧凑化靠减少空白、折叠次要内容、合并同类操作，不缩小文字和核心触控区。点星、清除、菜单与主要按钮保留约44px触控目标。
- 原因与依据默认折叠，已有内容提供可见标记；小结默认可输入。长小结有上限并允许展开，不挤压整页。
- 任务、历史、奖励中心、设置和二级弹窗同步采用相同密度、对齐与安全区规则。历史趋势不强制横向滚动；软键盘弹出时保证输入可见。
- 手机不承诺五张完整卡片都挤进首屏。以文字可读、触控准确和明显减少滑动为验收目标。

## 4. 今日总体评分的数据设计

建议新增独立的按日记录映射`dailyReviews[YYYY-MM-DD] = { stars: 0..5 | null, note, updatedAt }`，不加入固定`DIMENSIONS`，不写奖励账本。允许只写小结而不选星；空白与0不同。选星、修改、清除、删除小结都只影响该日记录，不触发经验、等级和徽章奖励。

日期沿用香港时间，支持历史补记与更正，未来日期禁止。无经验就没有总体评分补记扣分；不能把它当成第五项奖励维度。现有四项日完成标记保持；总体卡单独显示自己的记录状态。

### 兼容与同步

1. 保留数据库名、页面来源、包标识、账号namespace、Android证书和安装数据路径。
2. 旧快照缺少新映射时在副本规范化为空；旧账本、冻结参数、processed、revision及modifiedAt保持语义，不重算、不重发经验。
3. 新字段必须随本地保存、导出／导入、云快照和跨端回读完整保留，并严格校验日期、0～5整数／空值、文本上限和时间。
4. **不能仅说「可选字段所以兼容」**：上线前验证现有旧客户端读写新字段的实际行为。若旧端会丢字段，需要升级备份格式或添加能力／最低版本保护，旧端拒写新格式；迁移前保留完整原始副本。规则1.3不因新增无经验记录而改变，JSON格式最终编号由兼容试验确定。
5. 重复导入、云下载、版本升级不播放历史成长奖励。损坏记录拒绝替换，保存失败保留输入草稿。

趋势新增独立的总体星级序列，空白断线、0星显示在零轴，支持7／30天与单日小结回看。周期均值只除以实际有星级记录的天数，小结不自动算作0星。

## 5. 长期登录与同步修复

### 目标行为

访问令牌短期有效，依靠refresh token续期；不将访问令牌本身强行延长一个月。启动、恢复前台和即将过期时刷新，会话失效的请求只尝试一次受控刷新和重试，避免死循环和并发刷新互相使令牌失效。新的轮换凭证串行、原子地加密落盘；Windows和Android共享相同的状态定义和测试情景。

「30天未使用」指连续30天未在前台使用应用；更新活动时间需节流，后台定时同步不能无限延长闲置窗口。退出、修改密码／服务端撤销或实际refresh token失效仍需要重新认证。首次从旧会话升级时补充活动元数据，不把缺字段一律判为已闲置30天。

客户端能实现上述流程；实际持续登录上限还依赖CloudBase当前环境的刷新令牌策略。实施时必须读取非秘密的实际策略并测试；服务端若提前到期，需在已授权范围调整相应配置或如实报告限制，不能用本地登录标志伪造有效认证。

状态应明确区分：已同步、同步中、离线待同步、需要重新登录、服务暂不可用。无网络／暂时刷新失败不清除本机业务数据，也不把网络错误当作用户主动退出。离线展示既有账号记录不代表持有可调用云端的有效身份。

### 继承与上传保护

- 初次登录先读取并完整校验云快照，再确定本机账号快照的处理方向。云端与本机各自有内容时先保存双方恢复副本，再沿用现行较新快照策略；时间不可信或UID有歧义时提供明确的数据选择，不静默覆盖。
- 仅访客有记录且云端／账号确实为空时，可以引导将已有记录继承到已验证的当前账号；有两份内容时不直接合并账本或覆盖。原访客快照仍保留。
- 新邮箱如对应已有账号，只验证身份和读回，不灌入测试业务数据。当前账号的数据核查另用只读、数量／revision／UID匹配结果，报告不公开个人数据。
- 保留现有上传requestId、版本CAS、revision检查和上传期间新修改排队；账号切换时旧请求不能落入新账号。
- 任何需要用户真实凭据的验收由用户正常登录完成，不从本机账号或历史材料推断密码／邮箱，不记录明文凭证。

## 6. 首次启动登录引导

启动顺序：打开本地快照并恢复加密会话 → 展示应用 → 无会话且本安装尚未展示引导时打开可关闭登录框。启动动效完成后再显示，避免登录框被遮挡；恢复身份暂时超时不能闪现错误的登录要求。

提供「登录」「注册账号」「暂不登录，直接使用」及关闭按钮；关闭立即继续离线记录。安装级引导标记独立于业务备份，正常更新、导入、切页不重复弹。清除应用数据后视为新安装。会话30天闲置／撤销后的登录提醒单独处理，同样可关闭并保留离线使用。

首次安装的未登录界面立即体现登录入口，不让网络检查或云端错误阻塞本地使用。具体启动动画与引导的先后在真实双端验收时调整，功能目标以用户要求为准。

## 7. 启动检查更新

启动立即发起独立后台检查，网络超时不阻塞输入；发现**当前平台应用版本**更高时，在启动／已有弹窗结束后提示「当前版本还有最新版本」，展示当前／最新版本与「下载最新版本」「稍后再说」。

发布来源固定为已授权公开仓库`StuTuse/rater-tracker`。现有Release是prerelease，`releases/latest`不能作为唯一入口；读取发布列表并识别非Draft候选。Windows和Android版本独立比较，不能把日期批次tag或源码Release当作应用升级。建议后续Release附机器可读的更新清单，明确两端版本、下载URL、摘要、最低读取能力和未变端包来源，现有Release不修改。

纯文档Release不提示应用升级；未变端引用原包；预览用户可检测更高alpha，稳定渠道策略另按将来的正式发布要求确定。一次运行对同一版本只提示一次，关闭后保留设置页入口。

选择下载才打开明确的官方Release或对应包链接，不静默安装、不修改用户业务记录；Windows／Android各按现有安装流程覆盖更新。联网失败安静重试；仅用户主动检查时显示失败说明。真实下载路径、来源校验、摘要与升级数据保持须单独验收。

## 8. 动画处理与验收

- 原生WebView禁用overscroll，CSS同时覆盖正文、弹窗与内部滚动容器；保留正常滚动、输入选择及系统返回。
- 星级与经验从当前可见帧接续，快速连点取消旧反馈但不取消业务保存；优先transform／opacity，避免反复布局和阴影／滤镜大面积重绘。
- 页面切换只播放新内容组一次；保存、文字输入、同步回读时不让整页反复淡出／淡入。保留焦点、展开状态、草稿与滚动。
- 页面不可见暂停装饰动效，回来直接落到真实保存值；系统减少动态和完整／柔和／关闭偏好继续有效。
- 不承诺仅靠CSS修改达到固定FPS。用实际Android渲染、帧记录和连续操作观察确认，记录设备和检查范围。

| 验收组 | 关键场景 |
| --- | --- |
| 布局 | 360／390手机、700／800平板、横屏／分屏、桌面；200%文字、长备注、软键盘、安全区、无内容横向溢出 |
| 越界 | 顶部／底部快速拖动、短页面、长页面、弹窗嵌套滚动，内容不整体拉伸 |
| 评分兼容 | 旧备份、缺新字段、新字段往返、0／空白、只记小结、补记／删除、四项原账本和XP逐项一致 |
| 动画 | 连点增减星、切页／返回、保存与云回读重叠、升级与撤销、减少动态，不闪空、不阻塞输入 |
| 会话 | 访问令牌到期、刷新轮换后杀进程、离线一两天再开、前台跨日、30天闲置、撤销、网络失败、UID不匹配 |
| 同步 | 访客→空账号、有云数据、两端离线修改、上传中再保存、切账号、重试同requestId，不重复结算或误覆盖 |
| 更新 | 两端独立版本、纯文档Release、预发布、无包／坏清单／离线、关闭／下载、覆盖安装后原记录保持 |
| 引导 | 新安装无登录主动打开、关闭正常使用、注册／登录、升级不重弹、会话恢复不闪误提示 |

建议实施顺序：先讨论界面选型 → 用隔离数据验证兼容和会话 → 实施共享组件与Android适配 → 双端真实渲染及打包验收 → 沿原证书和既有发布流程发布。账号续期和同步排查可与界面讨论在同一会话推进，不派遣其他会话。
