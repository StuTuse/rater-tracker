# 双端工程与工作区隔离说明

> 本文保留原路径以兼容已有链接。此前的方案比较与未实施状态已过期；本页只记录当前结构和权威入口，不再作为工程草案或待审批事项。

## 当前工程结构

- `apps/windows`：Electron桌面应用入口与Windows专属封装。
- `apps/android`：Capacitor／Android应用工程与原生能力。
- `packages/core`、`packages/data`、`packages/ui`：共享结算、数据契约和界面模块。
- 根目录`src/`及`electron/`：兼容路径，按实际引用维护。

当前结算规则为1.3，备份格式为1。Windows与Android各自维护平台版本；Android更新还需递增`VERSION_CODE`并沿用既有签名。当前双端版本、命令和Release入口见[README](../README.md)及[双平台GitHub发布流程](双平台GitHub发布流程.md)。

## 工作区边界

主工作区`main`负责共享模块集成；独立开发worktree的登记及责任范围见[工作区隔离登记](工作区隔离登记.md)。登记表示当时的协作状态，不构成文件锁，也不保证路径、分支或HEAD永远不变。开始工作前检查Git状态和最新远程提交；不得在另一个工作区切换分支、覆盖未提交文件或提交他人暂存内容。

共同规则、共享数据结构和入口由明确的集成人负责。一个平台的专属变化按该平台验收；影响共享规则或数据时检查两端兼容与备份互导。工作区同步只能在检查实际状态后执行，不以本历史方案中列出的路径或提交作为当前状态依据。
